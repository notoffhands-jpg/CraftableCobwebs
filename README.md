# CraftableCobwebs

Paper plugin that lets you craft cobwebs. 4 string gives you a cobweb.

Cobwebs are normally only found in mineshafts and a few other places, which makes them annoying to get for traps or builds. String is easy to farm, so this fixes that.

## Install

Put `CraftableCobwebs.jar` in your `plugins/` folder and restart the server.

Made for Paper 1.21.11. Server-side only, players don't need anything installed.
